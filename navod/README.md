# Rodokmen s Claudem – návod a startovní sada

Tahle složka je pro každého, kdo si chce s Claude Code udělat vlastní rodokmen: výzkum v matrikách, interaktivní web na GitHub Pages, tiskový plakát 2,5 × 1 m a 3D animaci předků.

**Ukázka hotového webu:** https://mv911t.github.io/Rodokmen/ (záložky Rodokmen, Širší okruh, Odkud jsme, Tisková verze, Animace)

## Co tu je
- **`CLAUDE.md`** – kompletní návod pro Clauda (pravidla, postup, archivy, čtení matrik, web, plakát, animace, předání).
- **`starter/`** – hotové nástroje s vymyšlenou ukázkovou rodinou:
  - `web/` – web, data a nástroje na jejich úpravu, kontrolu a publikaci;
  - `05_nastroje/tisk/` – generátor plakátu.

  Generuje se automaticky z nástrojů původního projektu, takže je vždy aktuální.

## Jak začít
1. Stáhněte si repozitář (zelené tlačítko **Code → Download ZIP**) a rozbalte ho. Potřebujete jen složku `navod/`.
2. Vytvořte prázdnou složku pro svůj rodokmen, např. `~/Rodokmen`.
3. Zkopírujte do ní `navod/CLAUDE.md` a obsah `navod/starter/` (tj. složky `web/` a `05_nastroje/`).
4. Ve složce spusťte Claude Code a napište **„začni“**. Claude se zeptá na pár věcí (pro koho je rodokmen, co víte o rodině, jestli smí být web veřejný…) a provede vás zbytkem.

Budete potřebovat: Claude Code, účet na GitHubu (web běží zdarma na GitHub Pages), Node.js a Python 3 s Playwrightem (Claude je doinstaluje).

## Soukromí
Žijící osoby se na web dostanou jen v rozsahu, který rodina schválí (`publicLiving`: jen jména, nebo vše). Rozhodnutí je vždy na vás.
