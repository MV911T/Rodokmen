# Rodokmen Veselých

Interaktivní rodokmen Matěje Veselého na časové ose – větve Veselý, Woroň, Chmielek, Pacík, Matůšů, Struž, Jiřík a Opoloný.

**Web:** https://mv911t.github.io/Rodokmen/

- Každá osoba je umístěna podle roku narození, vpravo je stupnice let.
- Kliknutím na osobu se otevře detail: data, místa, povolání, sňatky, rodiče, děti, poznámky a prameny.
- Míra doložení: matrika / jiný doklad / rodinná tradice / kandidát.

## Úpravy

Data jsou v `data.js`. Po úpravě spusť `./build.sh` – vytvoří `index.html` (web) a `rodokmen.html`.

Prameny: matriky Moravského zemského archivu v Brně (Acta Publica) a Zemského archivu v Opavě (Digitální badatelna), rodinné doklady a paměti.
